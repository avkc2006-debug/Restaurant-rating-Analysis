# 🍽️ Restaurant Rating Analysis using Power BI

## 📌 Project Overview
Restaurant Rating Analysis is a data analytics project developed using Microsoft Power BI. It focuses on analysing restaurant ratings, customer preferences, cuisines, pricing, and restaurant performance through interactive dashboards and visualizations.

## 🎯 Objectives
- Analyse restaurant ratings and customer reviews.
- Identify the most popular cuisines.
- Compare restaurant ratings.
- Analyse restaurant pricing and average costs.
- Understand customer preferences and trends.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- Data Cleaning
- Data Visualization
- DAX (if used)

## 📊 Key Analysis
- Restaurant rating distribution.
- Popular cuisines.
- Average restaurant ratings.
- Cost comparison of restaurants.
- Restaurant performance analysis.
- Customer rating trends.
